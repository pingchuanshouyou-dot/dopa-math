# Dopa-Math

中学1年生の「正負の数」の計算を、ゲーム感覚でサクサク反復練習するWebアプリです。
勉強が苦手でも続けられるように、テンポのいい入力・ボス戦・ごほうび演出を詰め込んでいます。

- 公開ページ（GitHub Pages）: https://pingchuanshouyou-dot.github.io/dopa-math/
- 1つの `index.html` だけで動きます（サーバー不要）

## 遊び方

1. オープニング画面で「新規登録」または「ログイン」（名前とパスワード）
2. ワールドマップでステージを選ぶ
3. 式の答えを専用テンキーで入力。エンター不要で、正しい答えを打ち切った瞬間に正解
4. ステージをクリアすると星（★1〜3）がもらえ、★2以上で次のステージが開く

## 主な機能

| 機能 | 内容 |
|---|---|
| 専用テンキー | `0〜9`・`−`・`C` の12キー。押すとぷにっと弾み、💗✨が浮かぶ |
| 瞬間判定 | 正解を打ち切った瞬間に判定し、0.1秒で次の問題へ。まちがえた1文字だけ消える |
| 制限時間 | 1問ごとのタイマー。3秒以内の正解はスコア・ダメージ1.5倍、時間切れでハートが減る |
| ハート | 7個。まちがい・時間切れで減る。通常ステージは最後まで遊べ、ボス戦は0でGAME OVER |
| ヒント | 3秒入力がないと、最初に計算する所（ピンク）とぶつかる符号（水色）が光り、一言ガイドが出る |
| 🧪 弱体化 | 1ステージ3回まで。式の形と符号はそのままで、数字だけ1〜2に小さくする |
| ボス戦 | 各ワールドの4面と7面。コンボで与えるダメージが増え、FEVER中はクリティカル。ボスが吹き出しでしゃべる |
| 認定証カード | 結果画面に、称号・星・反射神経ランク・成績をまとめたスクショ向けカード |
| ランク | 1〜100。先のワールドほど、速く正確に解くほどXPがたまる |
| 着せ替え | 星の合計やランクで、ラテ・水色・ネオン・推し色のテーマが解放される |
| TikTok解禁ゲージ | 今日の正解数でたまるゲージ（％表示）。FEVER中は2倍でたまる |
| 🔥 連続記録 | 何日続けて遊んだかをマップに表示 |
| 記録 | 遊んだ日時・問題数・計算時間・最大コンボ・スコアを一覧表示 |
| LINEで送る | 親向けの「学習報告」文面をLINEで送れる |

## ワールド構成

| ワールド | テーマ | 内容 |
|---|---|---|
| 1 マイナスの草原 | カッコなしの加減 | 答えが負になる計算、負から始まる計算、3つの数の加減 |
| 2 カッコの迷宮 | カッコの攻略 | `+(+)`・`−(−)` の符号変換、カッコ付きの掛け算入門 |
| 3 反転の火山 | 正負の乗除 | 九九を使った掛け算・割り算、0の計算、2乗、3つの数の掛け算 |
| 4 四則の要塞 | 計算の順序 | 掛け算・割り算が先、カッコの中が先 |
| 5 魔王の城 | 分数と総まとめ | 同じ分母の加減、分母が消える掛け算、逆数の割り算、全ワールドのまとめ |

各ワールドは7ステージ（4面が中ボス、7面が大ボス）。答えはすべて整数になるように問題を作っています。

## データの保存先

- **Firebase未設定のとき**: 遊んでいるブラウザの中（localStorage）に保存されます。端末を変えたりブラウザのデータを消したりすると記録は消えます。
- **Firebase設定済みのとき**: 名前・パスワード・記録・ランク・星がFirebaseに保存され、別の端末からでも続きを遊べます。

### Firebaseの設定手順

1. [Firebaseコンソール](https://console.firebase.google.com) でプロジェクトを作る
2. 「ウェブアプリを追加」して表示される `firebaseConfig` を、`index.html` の下の方にある `FIREBASE_CONFIG` に貼る
3. 「Authentication」→「ログイン方法」で「メール/パスワード」を有効にする（名前から専用のアドレスをアプリが作るので、利用者がメールアドレスを入力することはありません）
4. 「Authentication」→「設定」→「承認済みドメイン」に `pingchuanshouyou-dot.github.io` を追加する
5. 「Firestore Database」を作り、「ルール」に次を貼って公開する（自分のデータは自分しか読み書きできない）

```
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

## 調整しやすい数値

`index.html` の中の定数で、ゲームバランスを変えられます。

| 定数 | 意味 | 今の値 |
|---|---|---|
| `NORMAL_N` | 通常ステージの問題数 | 12 |
| `HEARTS` | ハートの数 | 7 |
| `STAR3` / `STAR2` | ★3・★2になる残りハート | 5 / 3 |
| `BOSS_HP` | 中ボス・大ボスのHP | 100 / 150 |
| `BASE_DMG` | ボスへの基本ダメージ | 8 |
| `LIMIT` | ワールドごとの制限時間（秒） | 12 / 10 / 9 / 9 / 10 |
| `QUICK` | スピードボーナスの秒数 | 3 |
| `WEAK` | 弱体化の回数 | 3 |
| `DAILY` | TikTok解禁ゲージが満タンになるポイント | 50 |
